# Student Grade Tracker

## Project Overview
Student Grade Tracker is a Java desktop application
used to input, calculate, and manage student grades.

## Technologies Used
- Java
- Java Swing
- ArrayList
- JTable
- Object-Oriented Programming
- VS Code

## Features
1. Add student details.
2. Enter marks for five subjects.
3. Calculate total marks.
4. Calculate average marks.
5. Find highest and lowest scores.
6. Calculate student grades.
7. Display all student records.
8. Generate summary reports.
9. Identify the class topper.
10. Delete student records.
